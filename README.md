# spbpu

Учебные материалы, лабораторные, курсовые и сайд-проекты за время бакалавриата в **СПбПУ**, ИКНК (бывший ИКНТ), ВШПИ.

Репозиторий — коллекция [git submodule](https://git-scm.com/book/en/v2/Git-Tools-Submodules): каждый пункт ведёт в отдельный репозиторий.

```bash
git clone --recurse-submodules https://github.com/simonoffcc/spbpu.git
```
